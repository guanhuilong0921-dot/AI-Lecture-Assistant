# AI-Lecture-Assistant
# 📚 智能交互式学习平台 (AI-Lecture-Assistant)

> **项目背景**：本项目为中国人民大学高瓴人工智能学院四人小组为**《新生引导课》**开发的结课作业/项目原型 (MVP)。
> **核心理念**：打破传统手写笔记的局限，打造“解析-重构-拓展-输出”的交互式学习闭环。

---

## 🌟 项目简介

本项目是一个基于轻量级 Web 框架和多模态视觉大模型构建的智能学习助手。针对大学理工科（如高数、线代、经典力学等）学习中常见的复杂公式推导，本系统能够自动识别手写笔记，并一键转化为结构化的学习资产。

### ✨ 核心功能亮点
* 📸 **智能视觉解析**：接入强大的多模态大模型，精准识别手写板书与推导过程。
* 📝 **LaTeX 代码重构**：自动生成排版严谨、支持复杂数学公式与中文环境的标准化 LaTeX 源码。
* 💡 **考点与错因剖析**：不仅“抄”笔记，更由 AI 助教深入拆解推导逻辑与常见计算陷阱。
* 🧠 **解题逻辑可视化**：自动生成 Mermaid 语法代码，一键构建解题思维导图。
* 🎯 **举一反三变式题**：基于原笔记知识点，智能生成同类型拓展练习与提示。
* 🖨️ **按需定制 PDF 导出**：支持模块化勾选，调用本地环境将所选内容编译为高清纯净版中文 PDF 学习资料。

---

## 🛠️ 核心技术栈

* **前端交互**：`Streamlit` (纯 Python 轻量级响应式 Web 框架)
* **核心大脑**：`通义千问 Qwen-VL-Max API` (负责视觉 OCR、逻辑推理与 Prompt 格式化输出)
* **排版引擎**：`TeX Live / xelatex` (负责最终中文 PDF 的深度编译与排版)
* **图表渲染**：`Mermaid` (负责解题逻辑流向的渲染)

## 🚀 团队成员快速启动指南 (Local Development)

请项目组成员（尤其是前端统筹及测试排版人员）按照以下步骤在本地部署开发环境：

### 第一步：获取代码库
```bash
# 推荐使用 Git 克隆
git clone [https://github.com/guanhuilong0921-dot/AI-Lecture-Assistant.git](https://github.com/guanhuilong0921-dot/AI-Lecture-Assistant.git)
cd AI-Lecture-Assistant
```
*(注：未配置 Git 的同学，请直接点击 GitHub 网页右上角的绿色的 `Code` 按钮，选择 `Download ZIP` 下载并解压进入文件夹。)*

### 第二步：配置虚拟环境与依赖
强烈建议使用 Conda 隔离环境，防止底层依赖冲突。在终端（Terminal）中执行以下命令安装必备库：
```bash
pip install streamlit dashscope python-dotenv
```

### 第三步：配置核心 API 密钥（⚠️ 绝对机密）
为了系统安全，API 密钥已加入 `.gitignore` 黑名单，未上传至云端。**如果不配置此文件，系统将无法连通大模型！**
1. 在项目根目录（`app.py` 同级目录）下，手动新建一个名为 `.env` 的文本文件。
2. 将组长发放的密钥粘贴进去并保存，格式严格如下：
```text
QWEN_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 第四步：点火启动！
确保终端处于当前项目目录，并已激活对应的虚拟环境，运行：
```bash
streamlit run app.py
```
*(此时浏览器将自动弹出网页，即可开始测试上传笔记。)*

## ⚠️ 高级功能提示：PDF 编译环境要求

网页底部的 **“✨ 组装并编译为高清中文 PDF”** 属于重度本地计算功能。负责该模块测试的同学请确保满足以下前置条件：
1. 电脑已完整安装 **TeX Live** (推荐) 或 MiKTeX。
2. 确保 `xelatex` 命令已成功添加至 Windows/macOS 的系统环境变量 `Path` 中。
3. 若未配置此环境，点击编译按钮会抛出警告，但**完全不影响**网页端其他文字与代码模块的正常展示。
